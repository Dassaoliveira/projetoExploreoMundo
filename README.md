# 🌍 Explore o Mundo

Projeto desenvolvido para a disciplina de Desenvolvimento Web Front-End.

O site apresenta destinos turísticos de diferentes países, exibindo informações dinâmicas através de JavaScript e estrutura JSON. O objetivo do projeto foi criar uma aplicação responsiva, moderna e organizada, permitindo a navegação entre destinos e páginas de detalhes.

---

## ✨ Funcionalidades

* Página inicial com layout responsivo
* Carrossel de imagens utilizando Bootstrap
* Cards de destinos gerados dinamicamente via JavaScript
* Página de detalhes para cada destino
* Navegação entre páginas utilizando Query String
* Estrutura de dados em JSON
* Layout adaptável para desktop e dispositivos móveis

---

## 🛠️ Tecnologias utilizadas

* HTML
* CSS
* JavaScript
* Bootstrap 5


---

## 🌎 Destinos disponíveis

* Estados Unidos
* França
* Itália
* Japão

Cada destino possui:

* descrição
* informações gerais
* pontos turísticos
* imagens associadas
